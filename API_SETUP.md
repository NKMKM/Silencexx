# 🔧 Настройка API URL для мобильного приложения

## Проблема
Мобильное приложение Expo не может достучаться до `localhost:3000` на вашей машине, потому что это локальный адрес.

## Решение 1: Использование локального IP адреса (Рекомендуется для разработки)

### Шаг 1: Узнайте IP адрес вашей машины
```powershell
ipconfig
```
Найдите строку `IPv4 Address` - это ваш локальный IP (например: `192.168.1.100`)

### Шаг 2: Обновите файл `api.ts`
```typescript
return 'http://YOUR_IP:3000/api';
```
Замените `YOUR_IP` на ваш реальный IP адрес

### Шаг 3: Убедитесь что приложение и бэкенд в одной сети Wi-Fi

---

## Решение 2: Использование ngrok (Для доступа из интернета)

### Шаг 1: Установите ngrok
```bash
npm install -g ngrok
```

### Шаг 2: Запустите туннель
```bash
ngrok http 3000
```

### Шаг 3: Скопируйте public URL
Вы получите что-то вроде: `https://abc123def456.ngrok.io`

### Шаг 4: Создайте файл `ngrok-url.json` в корне проекта
```json
{
  "apiUrl": "https://abc123def456.ngrok.io/api"
}
```

### Шаг 5: Перезагрузите приложение

---

## Решение 3: Использование Expo Tunnel

Expo имеет встроенный туннель. Просто запустите:
```bash
npx expo start --tunnel
```

Это автоматически создаст туннель и приложение сможет достучаться до бэкенда.

---

## Проверка подключения

Если вы используете IP адрес, убедитесь что:
1. ✅ Мобильное приложение в той же Wi-Fi сети что и бэкенд
2. ✅ IP адрес правильный (пингуйте его: `ping YOUR_IP`)
3. ✅ Порт 3000 открыт (бэкенд запущен и слушает на этом порту)
4. ✅ Файервол позволяет подключения к порту 3000

---

## Текущая конфигурация в `api.ts`

Приложение автоматически выбирает:
- **Веб**: `http://localhost:3000/api`
- **Мобильное**: `http://192.168.100.120:3000/api` (по умолчанию)

Если этот IP неправильный, измените значение в функции `getApiUrl()` на ваш реальный IP адрес.

---

## Ошибки при подключении

### "Network Error" при отправке голоса
- Проверьте что URL правильный
- Проверьте что бэкенд запущен (`npm run dev` в папке `backend`)
- Проверьте что приложение может достучаться до API:
  ```bash
  curl http://YOUR_IP:3000/api/health
  ```

### Туннель не работает
- Если используете ngrok - проверьте что сессия активна
- Если используете Expo Tunnel - убедитесь что приложение запущено с флагом `--tunnel`
