# Контекст и повторное открытие чата

Исправлены три причины наблюдаемого поведения:

- Flutter отправлял `{role: 'model', text: '...'}`, а AI принимал `{role: 'assistant', content: '...'}`. Новый клиент отправляет правильный формат, сервер также понимает прежний для уже установленных клиентов.
- `/api/chat` записывал каждое сообщение в legacy-таблицу и `messages`. Чтение объединяло обе копии; прежняя проверка совпадения в пределах одной секунды ломалась на медленной БД. Новые пары записываются только в `messages`, атомарно. История для модели берётся на сервере из чата проверенного владельца; тот же читатель используется текстом, очередью и голосом.
- Инструкция модели разрешала выполнение произвольных задач. Теперь область ограничена эмоциональной поддержкой; явная просьба написать код получает локальный отказ с предложением обсудить переживания. Переживания о программировании/работе остаются допустимыми. Для остальных тем действует инструкция модели, а не обещание абсолютной защиты от любого обхода.

Совместимость истории: старые записи не удаляются из БД. При чтении зеркала сопоставляются один к одному по роли, точному тексту и времени до 60 секунд; современная копия приоритетна. Повторы внутри одной таблицы сохраняются. Это эвристика для исторических записей без общего ID: более давние зеркала могут остаться, а независимые одинаковые сообщения из разных таблиц в этом окне неотличимы от зеркал. Для точного исправления всех старых данных нужна сверка реальной БД/миграция идентификаторов; разрушительная очистка не запускалась.

В модель передаются последние 12 пригодных реплик в пределах общего QWEN_MAX_INPUT_CHARS. Это исправляет потерю контекста на каждом сообщении, но не добавляет бесконечную память или резюме всей переписки.

Перед использованием обновить и перезапустить запускаемую копию backend; для изменения клиента обновить Flutter-сборку. Старый клиент уже получает совместимость контекста через backend. Реальный Qwen, PostgreSQL пользователя и iPhone в этом прогоне не вызывались; проверены сборки, unit-тесты и Flutter-тесты.
