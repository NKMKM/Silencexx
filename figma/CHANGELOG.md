# 📝 Changelog

Все заметные изменения в проекте CloudMind будут задокументированы в этом файле.

## [2.0.0] - 2025-11-09

### 🎯 Главные изменения

Упрощение навигации и фокус на трех основных функциях приложения.

### ✨ Добавлено

- **Упрощенная нижняя навигация** с тремя вкладками:
  - 🏠 Главная (ChatPage)
  - 📅 Дневник (ThoughtsCalendar)
  - ⚙️ Настройки (SettingsPage)
- **Голосовой помощник** теперь доступен как модальное окно с кнопки микрофона
- **Улучшенный календарь мыслей** с визуальными подсказками
- **Обновленная документация**:
  - Переписан NAVIGATION_GUIDE.md
  - Обновлен QUICK_START.md
  - Обновлен README.md
  - Создан подробный SUMMARY.md

### 🔄 Изменено

- **ChatPage**: Убраны дополнительные элементы UI (QuickActions, DailyAffirmation, AmbientSoundscape, BreathingExercise)
- **VoiceAssistant**: Переделан из отдельной страницы в модальное окно с кнопкой закрытия
- **BottomNavigation**: Сокращено с 4 до 3 вкладок
- **App.tsx**: Переработана логика навигации для новой структуры
- **SettingsPage**: Убрана зависимость от `onNavigateToChat`, используется только нижняя навигация
- **ThoughtsCalendar**: Добавлены подсказки пользователям, улучшена визуализация

### ❌ Удалено

Следующие компоненты были удалены для упрощения приложения:
- `BreathingExercise.tsx` - Дыхательное упражнение
- `AmbientSoundscape.tsx` - Окружающие звуки
- `DailyAffirmation.tsx` - Ежедневные напоминания
- `QuickActions.tsx` - Панель быстрых действий

### 🎨 Улучшения дизайна

- Более чистый интерфейс главной страницы
- Фокус на основном функционале
- Улучшенная визуальная иерархия
- Плавные анимации переходов между вкладками

### 📚 Документация

- Полностью переписано руководство по навигации
- Обновлено руководство быстрого старта
- Обновлен главный README
- Создана подробная сводка проекта (SUMMARY.md)

## [1.0.0] - 2025-11-08

### ✨ Первый релиз

Полная система аутентификации и основные функции приложения.

### Добавлено

- **Аутентификация** с 4 способами входа:
  - Google OAuth
  - Apple ID
  - Email/Пароль
  - Телефон с OTP
- **Основные страницы**:
  - ChatPage - Чат с AI
  - ThoughtsCalendar - Календарь мыслей
  - VoiceAssistant - Голосовой помощник
  - SettingsPage - Настройки
- **Дополнительные функции**:
  - MoodTracker - Отслеживание настроения
  - BreathingExercise - Дыхательные упражнения
  - AmbientSoundscape - Звуки природы
  - DailyAffirmation - Ежедневные аффирмации
  - QuickActions - Быстрые действия
- **Система подписок**:
  - BillingPage - Выбор тарифа
  - PaymentPage - Оплата
  - CreditCardVisual - 3D визуализация карты
- **Безопасность**:
  - CrisisSupport - Поддержка в кризисных ситуациях
  - Определение кризисных сигналов в чате
- **UI компоненты**:
  - BottomNavigation (4 вкладки)
  - FloatingClouds - Анимированные облака
  - InteractiveParticles - Интерактивные частицы
  - MobileBackdrop - Затемнение фона
  - PremiumBanner - Баннер Premium
- **Документация**:
  - AUTH_AND_ACCOUNT_GUIDE.md
  - NAVIGATION_GUIDE.md
  - QUICK_START.md
  - TESTING_GUIDE.md
  - TEST_PAYMENT_INSTRUCTIONS.md
  - README.md

### Дизайн

- Облачная тематика с мягкими градиентами
- Glassmorphism эффекты
- Плавные анимации с Motion (Framer Motion)
- Адаптивный дизайн для мобильных и планшетов
- Цветовая палитра: голубой → фиолетовый → розовый

### Технологии

- React + TypeScript
- Tailwind CSS v4.0
- Motion (Framer Motion)
- Shadcn/UI компоненты
- Lucide React иконки
- React Hook Form для форм

## Формат версий

Проект следует [Semantic Versioning](https://semver.org/):
- **MAJOR** - несовместимые изменения API
- **MINOR** - новые функции с обратной совместимостью
- **PATCH** - исправления ошибок с обратной совместимостью

## Типы изменений

- **Добавлено** - новые функции
- **Изменено** - изменения в существующем функционале
- **Удалено** - удаленные функции
- **Исправлено** - исправления ошибок
- **Безопасность** - исправления уязвимостей
