# CloudMind - Твой спокойный компаньон 🌥️

Мобильное приложение для релаксации и эмоциональной поддержки с облачной тематикой. Разработано для помощи людям в расслаблении и борьбе с самокритикой.

## ✨ Миссия

Помочь человеку не утонуть в самокритике, научиться разговаривать с собой мягко, вернуть ощущение, что выход есть.

## 🎯 Основные функции

### 💬 Главная страница - Чат с AI

Основной интерфейс для общения с эмпатичным AI-помощником CloudMind:

- **Текстовый чат**: Делитесь всем, что у вас на душе
- **История разговоров**: Боковая панель с доступом к прошлым диалогам
- **Новые разговоры**: Создавайте свежие диалоги в любое время
- **Кризисная поддержка**: Автоматическое определение кризисных сигналов
- **Эмпатичные ответы**: AI говорит как спокойный, понимающий человек

**Примеры ответов:**
- "Похоже, ты действительно зол. Это нормально."
- "Сейчас ты, похоже, очень устал. Хочешь просто выдохнем минуту?"
- "Ты имеешь право быть в этом состоянии. Не нужно бежать."

### 🎤 Голосовой помощник

Интерактивный AI с красивой облачной анимацией:

- **Анимированное облачко**: Меняет состояние в зависимости от активности
- **Голосовое общение**: Нажмите на облачко и говорите
- **Визуальные эффекты**: 
  - Пульсирующие круги при прослушивании
  - Звуковые волны при ответе
  - Плавное свечение и вращение
- **История диалога**: Записи разговоров в нижней части экрана

### 📅 Календарь мыслей (Дневник)

Безопасное пространство для ежедневных записей:

- **Ежедневные записи**: Пишите о своих мыслях каждый день
- **Только сегодня**: Редактировать можно только сегодняшнюю запись
- **Просмотр прошлого**: Читайте старые записи, но не изменяйте их
- **Блокировка будущего**: Нельзя создавать записи заранее
- **Визуальные индикаторы**: 
  - Синий градиент - сегодня
  - Фиолетовый - есть запись
  - Серый - будущая дата (заблокирована)

**Философия календаря:**  
Прошлое остается неизменным, чтобы сохранить аутентичность ваших мыслей в моменте.

### ⚙️ Настройки

Полное управление аккаунтом и приложением:

- **Управление аккаунтом**: Профиль, безопасность, связанные аккаунты
- **Подписки и тарифы**: Free, Premium, Professional
- **Настройки приложения**:
  - Уведомления
  - Темная тема
  - Режим приватности
- **Поддержка**: Центр помощи, политика конфиденциальности, условия использования
- **Выход**: Безопасный выход из аккаунта

## 🚀 Навигация

### Нижняя панель (Bottom Navigation)

Три основные вкладки для быстрого доступа:

```
🏠 Главная  |  📅 Дневник  |  ⚙️ Настройки
```

- **Главная**: Чат с AI и голосовой помощник
- **Дневник**: Календарь для записи мыслей
- **Настройки**: Управление аккаунтом и приложением

## 🎨 Дизайн и UX

### Визуальная тема

- **Облачная эстетика**: Мягкие градиенты, плавающие облака, успокаивающие цвета
- **Цветовая палитра**: От голубого к фиолетовому и розовому
- **Анимации**: Плавные переходы с использованием Motion (Framer Motion)
- **Glassmorphism**: Эффекты стекла и размытия для современного вида

### Тон и подход AI

ИИ говорит так, будто рядом спокойный, понимающий человек:

- **Тихий, осознанный** — не "мотивирующий"
- **Эмпатичный** — признаёт чувства, не обесценивает
- **Без токсичной позитивности** — разрешает быть в моменте
- **Простой язык** — без профессиональных терминов

## 🔐 Аутентификация

Четыре способа входа:

1. **Google OAuth** - Вход через Google аккаунт
2. **Apple ID** - Вход через Apple
3. **Email/Пароль** - Классический вход по почте
4. **Телефон + OTP** - Вход по номеру телефона с кодом подтверждения

## 🛡️ Система кризисной поддержки

При обнаружении признаков серьёзного кризиса:

## 🎯 Целевая аудитория

CloudMind создан для людей, которые:
- Борются с самокритикой и негативными мыслями
- Ищут безопасное пространство для выражения эмоций
- Нуждаются в эмоциональной поддержке без осуждения
- Хотят практиковать рефлексию и осознанность

## ⚠️ Важное уведомление

**CloudMind - это инструмент для самопомощи, а не замена профессиональной терапии.**

- Не использовать для медицинских консультаций
- Не заменяет работу с психотерапевтом
- В экстренных ситуациях обращайтесь к профессионалам
- Мы не собираем PII (персональную идентифицируемую информацию)
- Приложение не предназначено для работы с чувствительными данными
