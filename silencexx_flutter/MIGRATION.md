# Перенос React Native → Flutter

## Реализовано в клиенте

| Исходные экраны / функции | Flutter |
|---|---|
| Splash, login, register, OTP | `main.dart`, `auth_screen.dart`; email/телефон, OTP, защищённый токен |
| Восстановление пароля | Письмо, ввод токена из ссылки, новый пароль |
| CosmosHub, ChatPage, ChatSidebar | Главная, список/удаление/создание чатов, временные чаты, история |
| Текст, настроение, лимиты | Существующий `/api/chat`, история, 7 настроений, ошибки и лимиты |
| VoiceRecorder, VoiceMessage | Запись AAC/Opus, multipart-upload, опрос статуса, воспроизведение |
| TextToSpeech | Системное озвучивание с проверкой права тарифа |
| Calendar, NewEntry, ViewEntry | Календарь, создание одной записи в день, история и AI-отклик |
| Daily tasks | Открытие, завершение и серия дней из backend |
| Inbox | Получение, отметка прочтения, отправка пожелания с cooldown |
| Profile / AccountSettings | Имя, телефон, аватар, пароль и подтверждение нового email |
| Devices / Sessions | Список активных сессий, завершение других сессий |
| Billing / Payment | Тарифы, остатки лимитов, отмена, история, явно обозначенная демо-оплата |
| PanicMode | Оценка тревоги, дыхание, 5 шагов grounding, обсуждение, завершение сессии |
| Theme / Language | Светлая/тёмная/системная тема; RU/EN с сохранением выбора |
| Reminders | Ежедневные локальные уведомления Android/iOS, выбор времени, отмена |

Сохранена палитра Aurora. Интерфейс переписан на Flutter Material 3 и адаптирован под
узкие и широкие экраны; Expo/Reanimated-анимации не переносятся побитно.
В исходном выборе языка было 14 пунктов, но реальный словарь только RU/EN;
в новом интерфейсе доступны именно эти два языка. Язык ответов AI передаётся в API;
ответы сервера и системные ошибки могут оставаться на языке backend.

## Backend

Исходники и миграции скопированы, сервер остаётся Node.js/Express: Flutter заменяет
клиент, а не серверную платформу. Исходный `../backend` не изменён.
В новой копии исправлены необходимые для переноса детали:

- В `package.json` объявлены `multer` и его типы для чистой установки.
- Python можно задать через `PYTHON_EXECUTABLE`; поддержан путь venv Linux/macOS.
- Профиль возвращает сохранённый аватар.
- При чтении истории исключаются зеркальные записи старых таблиц, если есть
  соответствующая запись в `messages` с тем же текстом/ролью в пределах секунды.
- Удаление чата также очищает сообщения из новой таблицы.
- Режим помощи принимает индекс grounding и передаёт ответ пользователя в AI.

SQL и данные пользователя не изменялись. Реальная интеграция требует работающих
PostgreSQL, Redis, Ollama и, для голоса, Python-распознавания. Полная проверка с вашей
БД, микрофоном, SMTP, OAuth и платёжным провайдером не выполнялась.

## Внешние интеграции и ограничения

- Оплата в исходном backend — симуляция. Flutter не запрашивает данные банковской
  карты и не представляет этот сценарий как реальное списание.
- OTP-экран перенесён; сервер исходного проекта хранит OTP в памяти и не подключает
  полноценного SMS-провайдера. Отправка SMS требует серверной интеграции.
- Google/Apple обработчики клиента реализованы, но по умолчанию скрыты до настройки
  идентификаторов, подписей и серверной проверки токенов. В исходном backend OAuth
  требует отдельной проверки готовности перед production.
- Для Google Android/iOS задайте `ENABLE_GOOGLE_SIGN_IN=true`, `GOOGLE_CLIENT_ID`
  (при необходимости) и `GOOGLE_SERVER_CLIENT_ID`; настройте SHA fingerprints и
  iOS URL scheme в консоли провайдера и платформенном проекте. Web Google-вход
  требует отдельной интеграции рекомендованной провайдером кнопки; не включайте
  мобильный сценарий для Web.
- Apple включается `ENABLE_APPLE_SIGN_IN=true` на iOS после настройки Sign in with Apple
  capability и provisioning в Xcode. iOS-сборку нужно проверять на macOS.
- Ссылки восстановления/смены email сейчас используют ввод токена из письма.
  Universal Links/App Links и автоматический переход из письма не настроены.
- Напоминания доступны на Android/iOS; Android может сдвигать время уведомления
  из-за энергосбережения. Изменение часового пояса требует повторного сохранения времени.
- Временный чат скрывается из списка согласно исходному API; это не обещание
  автоматического удаления серверных данных.
- Release-подпись Android и Apple provisioning остаются задачами публикации.
  Web собирается в JavaScript; WebAssembly не поддерживается выбранной версией
  `flutter_secure_storage_web`.
- Загрузка на GitHub не выполнялась: предыдущее разрешение на проверку репозитория
  было отклонено. Эта папка подготовлена независимо от публикации.

## Проверка перед выпуском

На тестовом сервере пройти регистрацию/OTP, повторный вход, истечение сессии,
текст/голос/историю, отказ микрофона, дневник, задания, почту, обновление профиля,
смену email/пароля, лимиты, демо-платёж, режим помощи и уведомления после перезапуска.
Тесты с mock API проверяют контракты клиента и не заменяют эти проверки на устройстве.
