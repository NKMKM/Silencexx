# Исправление структуры, 25 октября 2026

Предыдущая итерация меняла компоненты и стили, но сохраняла стартовый чат, историю в drawer и дневник с редактором при входе. Эта итерация меняет именно эти сценарии. Остальные экраны не объявляются повторно полностью перестроенными.

| Область | До | После |
|---|---|---|
| Вход | Пустой чат с композером | «Сегодня»: разговор, продолжение последнего диалога, дневник, практика и дыхание |
| Разговоры | История как drawer поверх чата | Самостоятельный основной раздел; поиск, недавние/архив, действия с диалогом |
| Открытый чат | Композер конкурирует с нижним dock | На телефоне отдельный фокусный экран без dock; возврат в библиотеку |
| Черновик | Новый чат и возврат к текущему разговору легко спутать | Явное «Продолжить черновик» в библиотеке, отдельное создание нового чата |
| Дневник | Редактор и архив как соседние вкладки | Коллекция при входе; отдельный режим написания/чтения; возврат к коллекции |
| Навигация | Пять разделов, настройки среди основных, скрытый drawer | Сегодня / Разговоры / Дневник / Практики / Сообщения; настройки через кнопку на «Сегодня»; drawer удалён |
| Desktop | Контекстная история видна сразу | Стартовый экран; библиотека как раздел; контекстная колонка только внутри открытого чата |

Сессии ConversationSession, загрузка контекста, запись аудио, API и сохранение дневника сохранены. Переключение разделов по-прежнему блокируется во время записи. Скрытые страницы сохраняют состояние, их TickerMode отключён. Переход библиотека/чат использует существующий RetainedPageStack с учётом уменьшения движения.

## Файлы

- `lib/screens/home_screen.dart`: новый граф переходов, стартовый раздел, фокусный чат, удаление drawer, возврат из записи дневника системной кнопкой.
- `lib/screens/today_screen.dart`: новый ежедневный вход; существующие данные workspace, без дополнительных запросов и вымышленных статистик.
- `lib/widgets/conversation_sidebar.dart`: самостоятельный режим библиотеки, новая иерархия строк, создание диалога в заголовке, возобновление черновика.
- `lib/screens/journal_screen.dart`: коллекция → редактор/чтение; удалено прежнее раскрытие записи внутри списка.
- `lib/screens/auth_screen.dart`: исправлена адаптивность разделителя email при увеличенном тексте.
- `test/app_test.dart`, `test/design_test.dart`, `test/features_test.dart`: новые переходы, сохранение черновиков, чтение записей и регрессии.
- `tool/make_structure_review.py`: отдельная галерея доказательств этой итерации, включая сравнение в оттенках серого.

## Проверки

Новая проверка маршрутов проходит сценарий «Сегодня → библиотека → новый чат → назад → продолжить черновик → дневник → написать → системный назад». Проверяется исчезновение dock в разговоре и сохранность текста.

Матрица новых экранов: 320×720 с масштабом текста 2×, 390×844, 768×1024, 1280×900; тёмная и светлая темы. Остальные существующие проверки продолжают проверять сообщения, упражнения, формы, меню, клавиатуру и доступность. Протоколы фактического последнего запуска — в `build/structure-after/evidence/`.

Снимки получены из Flutter widget tests с тестовыми данными. Исходники сравнения — предыдущая итерация этой рабочей копии (`build/structure-before`), не старый git HEAD. Галерея: `build/structure-after/index.html`. Кадры перехода сняты с шагом 50 мс, это не измерение FPS.

Профилирование взаимодействий на физическом iPhone и Android в этой итерации не выполнено. Это не загрузка в TestFlight.

На Mac обнаружены одновременно установленная `/Applications/CloudMind.app` и отдельная сборка проекта. Изменение исходников не обновляет установленную копию. Для проверки новой структуры запускается сборка из `build/macos/Build/Products/Profile/`.

Фактический результат финальной проверки: **58 тестов прошли**, `flutter analyze` без замечаний; источник UI-аудита — 29 Flutter-файлов и 4 native UI-файла, без непроверенных изменений в реестре. В галерее 179 снимков, включая кадры перехода. macOS profile-сборка завершена и запущена отдельным экземпляром из проекта.

iOS simulator debug-сборка также завершена и установлена. При реальном запуске приложение показало стартовую ошибку (экран повторного подключения/входа); авторизованные сценарии на симуляторе не подтверждены. Отдельный реальный снимок — `device-ios-simulator.png`. Новая структура показана и проверена в widget tests с тестовыми данными; это ограничение не скрывается.
